## 📌 Executive Summary

Комплексное End-to-End аналитическое решение для оценки продаж, клиентской базы и операционных метрик e-commerce бизнеса. Проект построен на практической связке ключевых инструментов аналитика:

* **Excel:** Первичный аудит сырых данных, поиск и удаление дубликатов.
* **T-SQL (SQL Server):** Решение прикладных бизнес-задач, фильтрация данных, расчет конверсий, отмен и сегментация аудитории.
* **Power BI:** Создание семантического слоя (DAX-меры) и сборка интерактивного двухстраничного дашборда с кросс-фильтрацией для визуализации инсайтов.

## ⚡ Analytical Logic & Governance Matrix

| Бизнес-вопрос | Решение (Стек) | Результат |
| :--- | :--- | :--- |
| **Оптимизация выручки:**<br>Как избежать завышения Revenue из-за отмененных заказов? | Отфильтровали данные в SQL и написали меру в Power BI (`CALCULATE` по статусу `delivered`). | Исключили завышение выручки на 74.2% ($59.1M против реальных $15.2M). |
| **Расчет отмен:**<br>Как точно оценить процент отмен и возвратов по компании? | Использовали точное деление и расчет метрик в Power BI (`DAX / SQL`). | Зафиксировали общий уровень отмен на отметке 24% для логистики. |
| **Маркетинговый бюджет:**<br>Какая возрастная группа приносит основную прибыль? | Провели сегментацию клиентов по возрастам в Power BI (`age_group`). | Выявили целевую группу 36–50 лет ($19.5M выручки) для таргетинга. |
| **Эффективность оплат:**<br>Какие платежные системы доминируют в транзакциях? | Провели агрегацию долей платежных систем в SQL/Power BI (`GROUP BY payment_mode`). | Установили, что UPI занимает 32.71%, а кредитные карты — 17.29%. |

## 💡 Бизнес-рекомендации на будущее (Strategic Action Plan)

1. **Перераспределение маркетинга:** Направить основной рекламный бюджет на сегмент **36–50 лет (драйвер выручки на $19.5M)** и запустить для них персонализированные программы лояльности.
2. **Оптимизация чекаута и комиссий:** Сделать платежный метод **UPI (32.71% транзакций)** приоритетным на первом экране оплаты, а также передоговориться с банками о снижении эквайринговых комиссий.
3. **Борьба с 24% отмен:** Внедрить обязательный автоматический опрос при отмене заказа для выявления главных причин (проблемы с логистикой, долгая доставка или неудобная оплата).
4. **Контроль завышения показателей:** Закрепить использование фильтрации по статусу `delivered` в SQL как единый стандарт (Single Source of Truth) для финотдела, чтобы исключить ошибки в бюджетировании.
